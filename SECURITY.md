# Security reporting

This local protocol MVP has not been audited or deployed to a public network. Do not send real funds to an unreviewed deployment.

For a suspected exploitable issue, use this repository's GitHub **Report a vulnerability** feature if maintainers enable it. No private security email or response SLA has been supplied. If that feature is unavailable, ask the maintainer for a private reporting channel without publishing exploit details. Ordinary non-sensitive correctness bugs may be filed as issues.

See `docs/security.md` for contract powers, trust assumptions and limitations. A production incident-response owner and disclosure policy remain to be assigned.
